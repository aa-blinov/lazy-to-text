Press a hotkey, speak, paste.

Lazy to Text listens on a global hotkey, transcribes on your computer with ONNX Runtime, and pastes the result into the window you were typing in. Audio never leaves the machine. The network is used to download a model, and, only if you turn on post-processing with a cloud provider, to send the text to it.

What happens between the hotkey and the text

  1. CtrlF2starts

    Press

    Ctrl+F2 starts a recording on Windows, Ctrl+F8 on macOS. Ctrl+F3 or Ctrl+F9 stops it and transcribes. Ctrl+F6 or Ctrl+F10 cancels. All three can be changed in Settings.

  2. CtrlF3stops

    Speak

    A model on your computer recognises the speech. The status pill names the accelerator that runs it: CUDA or TensorRT on Windows, CoreML on Apple silicon. If one of them fails, the app falls back to the CPU and the pill says so.

  3. CtrlVsent by the app; Cmd V on macOS

    Paste

    The text goes to the clipboard and into the window that had focus, with one paste keystroke. A popup in the bottom-right corner shows what was pasted, with the text itself.

The app itself, not a mock-up

These screenshots come from this repository’s code. The sidebar lists Models, Transcribe, History, Logs, Post-processing and Settings, and Ctrl+1 to Ctrl+6 switch between them.

Sixteen models, one inference path

Every model is an ONNX export loaded by the same backend and run by the same ONNX Runtime. There is no PyTorch, NeMo or CTranslate2 in the dependency tree, so the install stays the same size whichever model you pick.

The accuracy and speed columns are our own measurements: 400 clips from the Golos test split, run on the CPU. Spoken numbers are scored separately, because the corpus spells them out and the models write digits. On 1554 reference words the 95% confidence interval is roughly ±1 to 1.8 points, so a gap under about 2 points is a tie.

  • Vosk Small scores better than GigaAM v3, but it returns plain lowercase text. GigaAM v3 punctuates and capitalises its output, which is why it is the default for text that goes into a document.
  • Spoken numbers split the table. FastConformer RU, Parakeet TDT and GigaAM Multilingual write them correctly. The GigaAM v3 default and both Whisper cards garble them.
  • The test set is read voice-assistant commands, two seconds each. Treat these figures as the floor of what the models handle, not the ceiling.

Around the dictation

Transcribe files

Drop a WAV, FLAC, OGG, OPUS or AIFF file on the Transcribe tab. MP3, M4A, MP4, MOV, MKV and WebM go through a bundled ffmpeg, so nothing else needs installing. The transcript is editable before you copy it.

History

Up to 1,000 dictations are kept on this computer. Open one to read the full text, copy it in one click, or export the list as plain text.

Logs

Lines are colour-coded by level and source. Network lines are hidden until you ask for them, and the buffer can be searched.

Optional clean-up, off by default

After recognition, a language model can rewrite the text before it is pasted: clean it up, make it concise, or turn it into formal prose. You can also write your own instruction. Numbers come out as digits, and the language never changes.

Speech is always recognised on your computer. A cloud provider receives the words the model produced, so that choice is yours to make. If the model cannot answer, the raw transcription is pasted and the reason goes to the log.

Windows

The installer and the portable zip contain the same app. Use the zip where you cannot run an installer.

macOS

The archive unpacks to a double-clickable app: 148 MiB to download, 447 MiB installed. The first launch needs two permissions, Accessibility for the global hotkeys and the paste keystroke, and Microphone for recording. macOS never asks by itself, so Settings links to the right pane. The build is signed with a local certificate, so on another Mac you may have to right-click the app and choose Open the first time.
